# Premium Web Design

Use this skill when designing or improving websites, landing pages, marketing pages, product pages, or web app interfaces.

## Workflow
1. Understand the audience, product, primary action, content, and constraints. If details are missing, make sensible assumptions and state them briefly.
2. Establish a clear visual concept before writing markup: mood, typography, palette, grid, spacing, imagery, and signature interaction.
3. Avoid generic AI-looking layouts. Do not default to a gradient hero, a row of identical cards, excessive rounded rectangles, or meaningless decorative blobs unless the brief justifies them.
4. Use specific, credible copy. Replace placeholder text with realistic content that fits the product and audience.
5. Design responsive states for mobile, tablet, and desktop. Prioritize readable line lengths, touch targets, and clear hierarchy.
6. Use consistent design tokens for color, type, spacing, borders, shadows, and radii.
7. Ensure contrast, keyboard usability, visible focus states, semantic structure, and reduced-motion support.
8. When code is requested, provide working implementation rather than only a concept. Respect the project's existing stack and conventions.
9. Before finishing, review the result against the brief: hierarchy, spacing, consistency, responsiveness, accessibility, performance, and primary conversion goal.

## Output
- Briefly state the art direction and key decisions.
- Deliver the requested design or code.
- Call out assumptions and any unverified behavior honestly.
